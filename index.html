Calculadora FLUIG

Aprovador comercial com base de preços, regras ativas, média de volume dos últimos meses, margem mínima ajustada ao volume e justificativa pronta para copiar.

1. Base da operação usuário comum

A base de preços é carregada automaticamente pelo arquivo precos_atuais.json. A base de regras é carregada automaticamente pelo arquivo regras_ativas.json.

2. Regra ativa do cliente

Digite parte do nome do cliente e selecione a opção correspondente. A calculadora irá buscar a regra ativa e preencher automaticamente o volume atual mensal com base na média dos últimos 3 meses.

7. Justificativa para copiar no FLUIG

Detalhe da regra

Margem mínima requerida = margem base da faixa de volume + adicional de risco quando o volume não for garantido.

Faixas usadas: até 1.000 L = R$ 0,30/L; 1.001 a 5.000 L = R$ 0,25/L; 5.001 a 20.000 L = R$ 0,20/L; 20.001 a 50.000 L = R$ 0,15/L; acima de 50.000 L = R$ 0,12/L. Piso absoluto: R$ 0,10/L. Volume não garantido: +R$ 0,03/L.
